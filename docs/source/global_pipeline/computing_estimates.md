# Computing estimates

_If you have any questions, others probably do as well. Ask working group 14 to clarify with additional documentation._

## Overview

Each working group should provide their total computing estimates for all their use cases. This includes anything
running in the automated global pipeline, but also any additional resources that will be run on Roman Project resources
(e.g., SMDC). If you plan to run on external computing resources, we would still like this recorded, but these estimates 
should be separate.

Most reports will consist of two main components: the total CPU core hours you are estimating you will use and the
total storage space you expect to use. However, this should be provided with notes showing how you reached these 
calculations, along with a brief description of when you will be using these resources (e.g., spead out through each 
season, only after each season, etc.).

The previous round of estimates is recorded [here](https://rgespit.atlassian.net/wiki/x/AYAeCg), which you may want
to use as your basis for your updated estimates.
